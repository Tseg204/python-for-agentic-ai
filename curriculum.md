# Python for Agentic AI: curriculum

20 sessions, 30 minutes each, 3-4 per week (about 6 weeks).
Each session lists its goal and the skill tags used for tracking.

## Module 1: Python basics

| # | Topic | You'll be able to... | Skills |
|---|-------|----------------------|--------|
| 1 | Setup, running a file, `print`, variables | Run a Python file and store an agent's settings in variables | `running-code`, `print`, `variables` |
| 2 | Strings and f-strings | Build a prompt from pieces, like `f"Summarize: {text}"` | `strings`, `f-strings` |
| 3 | Numbers, `True`/`False`, `if`/`else` | Make a decision, like "stop if steps > max_steps" | `numbers`, `booleans`, `conditions` |
| 4 | Lists | Keep a chat history and a to-do list for an agent | `lists` |
| 5 | Loops (`for`, `while`) | Write the "keep going until done" loop every agent has | `loops` |

## Module 2: Data the way agents use it

| # | Topic | You'll be able to... | Skills |
|---|-------|----------------------|--------|
| 6 | Dictionaries | Write chat messages like `{"role": "user", "content": "hi"}` | `dicts` |
| 7 | Functions | Write small functions that later become agent tools | `functions` |
| 8 | JSON | Turn AI output text into Python data and back | `json` |
| 9 | Files and errors | Save notes to a file, and stop an agent from crashing with `try`/`except` | `files`, `errors` |

## Module 3: Real-world Python

| # | Topic | You'll be able to... | Skills |
|---|-------|----------------------|--------|
| 10 | Packages, `uv`, `.env` | Install libraries and load your API key safely | `packages`, `env-vars` |
| 11 | Classes, simply | Read SDK code that uses classes and objects | `classes` |
| 12 | Web APIs with `httpx` | Fetch data from the internet in Python | `http-apis` |

## Module 4: Building agents

| # | Topic | You'll be able to... | Skills |
|---|-------|----------------------|--------|
| 13 | First AI call | Send a message to Claude and print the reply | `llm-calls` |
| 14 | Chat memory | Keep a multi-turn conversation going | `llm-calls`, `chat-memory` |
| 15 | Tools | Describe a Python function so the AI can ask to use it | `tool-definitions` |
| 16 | The agent loop | Run the tool the AI asks for, send back the result, repeat | `agent-loop` |
| 17 | Multiple tools, bad calls | Give an agent several tools and handle mistakes | `agent-loop`, `errors` |
| 18 | Structured output, multi-step | Get clean data back and chain steps together | `structured-output`, `agent-loop` |

## Module 5: Capstone

| # | Topic | You'll be able to... | Skills |
|---|-------|----------------------|--------|
| 19 | Build your own agent | Plan and build a small agent (for example a notes or file helper) | `capstone` |
| 20 | Finish, final quiz, report | Finish it, take a final quiz across everything, get your improvement report | `capstone`, all |

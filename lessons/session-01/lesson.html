Session 1 of 20 · Python for Agentic AI

Your first lines of Python

Today you'll run a Python file, make it print things, and store an agent's settings in variables.

Why this matters

Every AI agent is a loop written in Python

An AI agent is a program that works on a task step by step. It thinks, does something, checks the result, and repeats until it's done. The "thinking" part is an AI model. Everything around it, the loop, the memory, the tools, is plain Python. That's what you're learning.

Step 1

Running a file

Python code lives in files that end in .py. You run one by typing python3 and the file name. Python reads the file from top to bottom, one line at a time.

# hello.py
print("Hello, agent!")
print("Ready to work.")
$ python3 hello.py
Hello, agent!
Ready to work.
Lines starting with # are comments. Python skips them. They're notes for humans.
Step 2

print shows things on screen

print(...) displays whatever you put in the brackets. Text goes inside quotes. You can print several things at once by separating them with commas. Python puts a space between them.

print("Steps left:", 3)
Steps left: 3

For an agent, print is how you watch what it's doing. You'll use it constantly to debug (find and fix problems).

Step 3

Variables are labeled boxes

A variable is a name that holds a value. You make one with =. Think of it as putting something in a box and writing a label on it. Later you use the label to get the value back.

Step 4

Text vs numbers

Quotes matter. They tell Python "this is text". Without quotes, 5 is a number you can do math with.

Text (called a "string")

max_steps = "5"
Just the character 5. Can't do math with it.

Number (called an "int")

max_steps = 5
A real number. max_steps + 1 gives 6.
Variable names: use lowercase and underscores, like agent_name. No spaces, and don't start with a number.

Watch out

Common beginner mistakes

  • Missing quote: print("hello) crashes. Every opening quote needs a closing one.
  • Using a variable before making it: Python reads top to bottom, so print(task) on line 1 fails if task = ... is on line 2.
  • Capital letters: Agent_name and agent_name are two different names.
  • Quotes around a variable: print("agent_name") prints the word agent_name, not what's inside the box.

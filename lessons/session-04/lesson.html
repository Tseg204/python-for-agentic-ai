Session 4 of 20 · Python for Agentic AI

Lists

Today your agent gets a memory and a to-do list.

Why this matters

An agent's memory is a list

When you chat with an AI, it doesn't really "remember" you. Your program keeps every message in a list and sends the whole list each time. Agents also keep a list of tasks: things still to do. So lists are everywhere in agent code.

Step 1

Making a list

A list is many values in one variable. Square brackets around it, commas between items.

tasks = ["search the web", "read the page", "write a summary"]

Each item has a position number, called an index. Python starts counting at 0, not 1. You can also count from the end with negative numbers. Click a box.

blue = counting from the start · purple = counting from the end
tasks[-1] is the handiest one: it always gets the last item, no matter how long the list is. Agents use it to grab the newest message.
Step 2

Adding with append, counting with len

.append(x) sticks a new item on the end. len(x) tells you how many items there are. This is a chat history being built, one message at a time. Type something and append it.

history = []    # an empty list to start
Don't write history = history.append(x). append changes the list in place and gives back nothing (None). Just write history.append(x) on its own line.
Step 3

Taking things out with pop

When the agent finishes a task, it takes it off the list. .pop(0) removes the first item and hands it back, so you can save it in a variable.

done = tasks.pop(0)
print(f"Done: {done}")
print(len(tasks))
.pop() with nothing inside removes the last item instead.
Step 4

Is it in there? in

x in my_list asks "is x somewhere in this list?" and gives True or False. Great with if. Here the agent checks whether a tool is blocked before it uses it.

blocked_tools = ["delete_files", "send_money"]
Step 5

Taking a slice

An AI can only read so much at once. So agents often send just the newest few messages. A slice gets part of a list: history[-3:] means "from 3 from the end, to the end".

Step 6

Predict the output

Guess first, then click.

Watch out

Common beginner mistakes

  • Starting at 1: the first item is tasks[0], not tasks[1].
  • Going past the end: a list of 3 has [0], [1], [2]. Asking for [3] crashes with IndexError.
  • Saving what append gives back: x = x.append(...) turns your list into None.
  • Missing commas: ["a" "b"] quietly glues them into one item, "ab".
  • Round brackets: lists use square ones [ ], both to make them and to get items.

Session 3 of 20 · Python for Agentic AI

Numbers and decisions

Today your agent learns to count, and to decide when to stop.

Why this matters

Every agent keeps asking "should I keep going?"

An agent works in steps. After each step it checks: am I done? Did I run out of steps? Did I spend too much? Each check is a yes/no question about numbers. Today you'll write those checks.

Step 1

Three new kinds of values

You know strings (text). Here are three more. No quotes on any of them.

5
int: a whole number
like a step count
2.4
float: a number with a dot
like a cost in dollars
True
bool: True or False
the answer to a yes/no question
Quotes change everything. 5 is a number. "5" is text that looks like a number. Python can do math with the first, not the second.
Step 2

Math, the Python way

Python does math like a calculator. Change the numbers and click a sign.

Dividing with / always gives a float, even 6 / 2 gives 3.0. Agents use math like this to count steps left or add up what an AI call cost.
Step 3

Comparing gives you True or False

A comparison asks a yes/no question about two values. The answer is always True or False. Move the sliders.

One = or two? = puts a value in a variable. == asks "are these equal?". Mixing them up is the number one beginner bug here.
Step 4

if / elif / else: picking a path

An if runs some code only when a comparison is True. elif means "else, if" (another check). else catches everything left. Python checks top to bottom and runs only the first match.

Here max_steps is 5. Slide step and watch which path the agent takes.

Step 5

The colon and the indent

Two small things make an if work. A colon : at the end of the line. And the code inside is pushed right by 4 spaces (that push is called an indent). The indent is how Python knows which lines belong to the if.

Breaks

if step > 5
print("Stop")
SyntaxError: expected ':'

Works

if step > 5:
····print("Stop")
print("Always runs")
The last line is not indented, so it runs either way.
Step 6

Joining checks: and, or, not

Sometimes one check isn't enough. These words join them, and they read like English.

if is_done or cost > budget:       # either one is enough to stop
    print("Stop")

if step < max_steps and not is_done:  # both must be True
    print("Keep going")
Step 7

Predict the output

Guess first, then click.

Watch out

Common beginner mistakes

  • = instead of ==: if step = 5: is an error. Asking needs two.
  • Forgetting the colon at the end of if, elif and else.
  • Forgetting to indent the lines inside, or indenting by different amounts.
  • Comparing text to a number: "5" == 5 is False. They are different kinds of values.
  • Writing true instead of True: it needs a capital T (and F).

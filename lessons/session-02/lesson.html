Session 2 of 20 · Python for Agentic AI

Strings and f-strings

Today you'll work with text in Python and build an AI prompt out of pieces.

Why this matters

A prompt is just a string you build

When an agent talks to an AI model, it sends text. That text is almost never typed out by hand. The agent glues it together from pieces: who the user is, what they asked, what step it's on. Today's skill is that glue.

Step 1

A string is a row of characters

Text in Python is called a string, like a string of beads. Each bead is one character: a letter, a digit, a space, a symbol. You make one with quotes. Single 'hi' or double "hi" both work. Just match them.

That's "Hi agent". 8 beads. The dashed one is the space, and it counts.

You can glue strings together with +. Python glues them exactly as they are, so you add spaces yourself.

user_name = "Sam"
print("Hi" + user_name)     # HiSam   (no space!)
print("Hi " + user_name)    # Hi Sam
Text with an apostrophe? Use double quotes outside: "Don't stop". With single quotes, Python thinks the string ends at the apostrophe.
Step 2

String tools

Strings come with built-in tools called methods. You use one by adding a dot and its name: text.upper(). They give you back a new string. The original stays the same.

Users type messy stuff. Agents clean it up before using it. Try it: type something (spaces at the ends are fine), then click a tool.

Step 3

f-strings: fill in the blanks

Gluing with + gets messy fast. An f-string is a string with an f right before the opening quote. Inside it, anything in curly brackets { } gets swapped for that variable's value. It's a fill-in-the-blanks template.

Change the boxes and watch the prompt rebuild itself.

prompt = f"Help {user_name} with this task: {task}"
print(prompt)
Step 4

Mixing text and numbers

Agents count steps, so you'll often put a number into text. With +, Python refuses to glue a string to a number. f-strings handle it for you.

With +

step = 2
"Step " + step
TypeError: can only concatenate str (not "int") to str

With an f-string

step = 2
f"Step {step}"
'Step 2'

"Concatenate" just means glue together. If you ever do need +, turn the number into text first with str(step).

Step 5

Predict the output

Guess first, then click.

Watch out

Common beginner mistakes

  • Forgetting the f: "Hi {name}" prints the curly brackets as they are.
  • Missing spaces with +: "Hi" + name gives HiSam.
  • Forgetting the brackets on a method: text.upper without () doesn't run the tool.
  • Expecting a method to change the original: text.strip() gives you a new string. Save it: clean = text.strip().

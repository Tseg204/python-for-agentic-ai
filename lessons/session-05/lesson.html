Loops

Today you write the "keep going until done" loop that's inside every agent.

Why this matters

An agent is a loop

An agent doesn't answer once and stop. It thinks, does something, checks the result, and goes round again until the job is done. In Python, "go round again" is a loop. Click through it.

round 1
Step 1

for: do something with each item

A for loop goes through a list one item at a time. Each time round, the variable task holds the next item. The indented lines are the body: what runs each time. Click Next line and watch.

You pick the name after for. for task in tasks reads like English, so it's a good habit: plural for the list, singular for one item.
Step 2

range: do it N times

Sometimes you don't have a list, you just want "do this 3 times". range(3) gives you the numbers 0, 1, 2. It starts at 0 (like list indexes) and stops before 3.

That's why the code prints i + 1: people count tries from 1, Python counts from 0.
Step 3

while: keep going until...

A while loop repeats as long as its condition is True. It checks before every round. This is the real agent loop: keep working while there are steps left.

steps += 1 is short for steps = steps + 1: "add one to steps".

The big danger: if nothing inside the loop ever makes the condition False, it runs forever. Delete steps += 1 and steps stays 0, so 0 < 3 is always true. That's why real agents always have a max_steps. If your program gets stuck, press Ctrl + C in the terminal to stop it.
Step 4

break: stop early

break jumps straight out of the loop, even if there are items left. Here the agent reads its inbox but stops the moment it sees "STOP".

Step 5

Keeping score as you go

A very common pattern: make a variable before the loop, change it inside, use it after. Here the agent counts how many of its tool calls failed.

Same pattern, but building a new list instead of a number:

log = []                          # before: empty
for task in tasks:
    log.append(f"done: {task}")  # inside: add one
print(log)                        # after: use it
Watch the indent: the print is not indented, so it runs once at the end. Indent it and it runs every time round.
Which one?

for or while?

for

You know what you're going through: every item in a list, or N times with range.

while

You don't know how many rounds: "keep going until the job is done". Always add a limit.

Watch out

Common beginner mistakes

  • Forgetting the colon: for task in tasks: and while x < 3: both end with :.
  • Forgetting to indent the body: lines inside the loop need 4 spaces. Python crashes with IndentationError otherwise.
  • Indenting too much: a print you want once at the end goes back to the left edge.
  • Never-ending while: make sure something inside the loop changes the condition. Ctrl + C gets you out.
  • Thinking range(3) includes 3: it gives 0, 1, 2.
